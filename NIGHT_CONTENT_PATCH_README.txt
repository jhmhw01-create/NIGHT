NIGHT CONTENT COLLECTIONS PATCH

GitHub jhmhw01-create/NIGHT의 현재 페이지를 기준으로 제작한 추가 패치입니다.
실제 저장소에 직접 업로드하거나 공개하지 않았습니다.

적용: ZIP을 풀고, 내용물을 기존 홈페이지 루트에 같은 경로로 업로드하세요.
index.html, gallery.html, fanclub.html은 기존 파일을 덮어씁니다.
기존 assets/css/style.css와 assets/js/main.js는 그대로 사용합니다.

추가된 입구
- HOME → NIGHT ORIGINALS (기존 NIGHT VLOG 옆)
- GALLERY → IF : NIGHT
- FANCLUB → WITH LUNA

신규 페이지
- with-luna.html: 멤버 5명, 각 3장면. 데이트 → 배웅 → 귀가 후 연락.
- if-night.html: 11개 IF 테마, 55장. 테마 선택 및 사진 확대.
- night-originals.html: 자체 콘텐츠 5편. 재생·일시정지·장면 이동·진행바.
  인터뷰·쿠키 장면·댓글 반응은 별도 추가 장면으로 표시합니다.
  꽃집 스페셜 6장은 #for-luna 코너에서 보며 WITH LUNA와 연결됩니다.

사진 113장과 웹용 썸네일 포함. 얼굴·헤어·이미지 내용 변경 없이 WebP로 변환했습니다.
자체 콘텐츠는 장면당 6초의 사진 슬라이드이며 실제 동영상·음성은 없습니다.
사진 확대는 닫기 버튼 또는 Esc로 닫을 수 있습니다.

검증: 이미지 226개(본문·썸네일) 읽기, 원본 113장 매핑, 신규 링크,
멤버/테마 선택, 재생/정지/탐색/다시 재생 확인.
기존 GitHub HOME에 이미 있던 PHANTOM MV 이미지 누락은 이 패치 범위 밖으로 그대로 두었습니다.
